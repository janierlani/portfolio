Connect to publish

Edit your bio, experiences, and essays here, then publish straight to your live site. To do that, Studio needs a GitHub token with permission to write to your portfolio repo. It is stored only in this browser.

One-time setup:
  1. Open github.com → Settings → Developer settings → Fine-grained tokens.
  2. Token name: portfolio-studio. Resource owner: janierlani. Expiration: your choice.
  3. Repository access → Only select repositories → pick janierlani/portfolio.
  4. Permissions → Repository permissions → Contents → Read and write.
  5. Generate, copy the token (starts with github_pat_), and paste below.

“Edit without connecting” lets you make changes and download an updated content.json to upload to GitHub yourself — no token needed.
