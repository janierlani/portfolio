Connect to publish

Edit everything on your site here, then publish straight to live. Studio needs a GitHub token that can write to your portfolio repo. It's stored only in this browser.

One-time setup:
  1. Open GitHub → Settings → Developer settings → Fine-grained tokens.
  2. Resource owner janierlani; Repository access → Only select → janierlani/portfolio.
  3. Permissions → Repository → Contents → Read and write. Generate & copy.

“Edit without connecting” lets you change things and download an updated content.json to upload yourself — no token needed (but image upload & one-click publish need a token).
